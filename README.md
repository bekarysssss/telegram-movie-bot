# Movie_Finder - Telegram-бот: каталог и подбор фильмов

Мой проект это Telegram-бот с собственной базой фильмов (PostgreSQL): поиск по русскому/английскому названию, жанры, годы,
рейтинги, случайный фильм с фильтрами, избранное, просмотренные с личными оценками, подбор по настроению,
похожие фильмы, статистика, веб-админка и импорт данных из TMDB / IMDb.

Проект: Для личного портфолио
Сфера деятельности: Бизнес-аналитика · Системная аналитика · Проектирование баз данных
Язык: Python
База данных: PostgreSQL

## Источники данных

| Источник | Что берём | Условия |
|---|---|---|
| **TMDB API** | названия (ru/en), описания, постеры, трейлеры, состав, жанры, страны, рейтинг TMDB, keywords | бесплатно для некоммерческого использования, **обязательна атрибуция** (есть в `/about` и ниже) |
| **IMDb datasets** | рейтинг и число голосов IMDb (`title.ratings.tsv.gz`) | только личное/некоммерческое использование |
| `data/seed_movies.json` | стартовые 79 фильмов, чтобы бот работал сразу без ключей | рейтинги в seed приблизительные — обновите командой `imdb-ratings` |

## Обзор

Movie Finder помогает пользователю найти фильм по названию или параметрам, выбрать случайный фильм с учётом предпочтений и вести собственную историю просмотров.
Проект также включает административные инструменты для управления каталогом и импорта информации о фильмах.

## Основные характеристики

Поиск фильмов
- Поиск по названию фильма.
- Фильтрация по жанру, году, рейтингу и другим доступным параметрам.
- Выбор случайного фильма с фильтрами.
- Просмотр популярных фильмов и карточек с информацией о фильме.
- Подбор фильма по заданным предпочтениям.
- Просмотр похожих фильмов.

Личная библиотека
- Добавление фильмов в избранное.
- Отметка просмотренных фильмов.
- Сохранение личных оценок.
- Просмотр пользовательской статистики.

Администрирование и управление данными
- Управление каталогом через веб-админку.
- Административная статистика и рассылка.
- Импорт и обновление данных о фильмах из внешних источников.


## Технологический стек

- Python — application logic.
- PostgreSQL — relational data storage.
- aiogram — Telegram bot interface.
- SQLAlchemy — database interaction.
- Alembic — database migrations.
- FastAPI / SQLAdmin — web administration interface.
- Docker Compose — application environment and service orchestration.
- pytest — automated testing.


## Обзор системы

Основные компоненты проекта:

- Telegram Bot — обрабатывает команды, действия пользователя и навигацию.
- Application Logic — выполняет поиск, фильтрацию и сценарии работы с пользовательской библиотекой.
- Database Layer — взаимодействует с PostgreSQL и хранит структурированные данные.
- External Data Sources — предоставляют информацию о фильмах и рейтингах.
- Admin Interface — предоставляет инструменты управления каталогом.


## База данных

В проекте используется PostgreSQL. Схема включает данные о фильмах, жанрах, странах, людях, пользователях, избранном и просмотренных фильмах.
Подробная ER-диаграмма и описание связей добавлены в docs/.

## Область охвата и ограничения
Проект создавался для себя, для поиска и подбора фильмов. Доступность функций зависит от конфигурации, внешних источников данных и среды запуска.
